El flux de treball del nucli

Així fa les webapps Novak Code, de la tasca a la web publicada. Tu escrius la tasca, aproves el pla i fusiones. La resta la fan els agents a GitHub, dins d'unes barreres que es comproven soles, amb el Mac apagat o encès. L'estat i els percentatges són els del repo pilot, la web de Novak Code.

Com és el procés

Cada canvi neix d'una tasca i d'un pla que tu aproves. Els agents de Claude l'escriuen a GitHub, el proven i obren el PR, sense necessitat del Mac. Vuit barreres limiten el que poden tocar, i uns canaris comproven de debò que funcionen. Només tu pots fusionar, i res arriba a la web sense passar les proves. Tot queda escrit: la tasca, el pla, el PR i el rebut.

Què t'aporta

Deixes de ser l'embut: només intervens en tres moments, i ho pots fer des del mòbil. La feina avança encara que no siguis davant de l'ordinador. Hi ha menys errors i més seguretat, perquè les claus i la branca principal estan protegides. El consum de la subscripció queda controlat amb els límits del dia. I cada webapp nova pot començar amb el mateix procés, sense muntar-lo de zero.

Qui fa cada cosa: el robot de GitHub i Claude

Al flux hi treballen dues màquines diferents. El robot de GitHub fa la feina fixa i vigila. Claude només entra quan cal llegir, entendre o escriure. A cada pas del camí hi ha una marca de color que diu qui el fa.

Programes fixos que s'engeguen sols

Es diuen GitHub Actions. Cada un és un fitxer de .github/workflows/.

  • S'engega quan passa alguna cosa: obres una tasca, poses una etiqueta, puges un commit, escrius un comentari. O a una hora fixa, com el resum del matí.
  • Fa sempre el mateix. No pensa ni s'inventa res: amb la mateixa entrada, el mateix resultat.
  • No gasta la subscripció de Claude.
  • Fa: canviar etiquetes, comptar els límits, la CI, la guarda, els canaris, obrir el PR amb l'app, els avisos i el resum per Telegram, i publicar la web.
  • Guarda les claus. Els secrets només els veuen els passos del robot, mai el model.

La CI és una part del robot: el control de qualitat que passa cada PR abans que el puguis fusionar.

Claude

El model d'IA, que el robot crida en quatre moments

Els agents del pla, el que implementa, el que respon i el revisor.

  • Llegeix i entén text: la tasca, el codi, els teus comentaris.
  • Escriu: un pla, codi o una resposta.
  • Gasta la subscripció. Per això hi ha els límits del dia, i un límit a 0 l'apaga.
  • Treballa tancat: només els fitxers permesos, sense terminal, sense claus i sense tocar els blindats.
  • No decideix sol. El que escriu, el robot ho comprova abans de pujar-ho, i la fusió sempre és teva.

Claude Code al Mac també és Claude, però a la teva sessió: és el camí interactiu, on treballeu junts.

Les regles

  1. @claude ha d'anar al principi del comentari, a la pestanya Conversation.
  2. Només fa cas dels teus comentaris: mira el teu usuari i el número del teu compte.
  3. Al PR, només si és de l'app de l'agent i és obert. En un PR teu o tancat respon «No ajusto aquest PR», sense gastar res.
  4. Un ajust cada vegada. Abans del següent, espera la resposta i els checks en verd.
  5. No serveix per a les zones delicades ni per tocar els blindats: per a això hi ha el camí interactiu.
  6. No fusionis el PR mentre esperes una resposta.

Les etiquetes de GitHub: el tauler de comandament

Les etiquetes són les marques de colors que porta cada tasca i cada PR, a la columna de la dreta. El robot les llegeix per saber què ha de fer. Algunes les poses tu, i d'altres les posa el robot sol. Cada tasca només té una etiqueta d'estat alhora.

Com se'n posa o se'n treu una
OrdinadorA la tasca o al PR, a la columna de la dreta, clica Labels (la rodeta ⚙). Marca o desmarca l'etiqueta i clica fora del menú: es desa sola.
Mòbil · app de GitHubObre la tasca, baixa fins a Labels, toca-ho i marca o desmarca l'etiqueta.
Des de TelegramTelegram només t'avisa: no pot canviar etiquetes. Toca l'enllaç de l'avís, la tasca s'obre a l'app de GitHub, i allà hi poses l'etiqueta. properament botons «Obre la tasca» i «Obre el PR» a cada avís.
